AnimeTagger Lite 快速开始
===========================

AnimeTagger Lite 是完全本地、离线运行的 Windows 便携软件。普通用户不需要
安装 Python。

一、选择发行包
--------------

* NVIDIA 显卡且驱动兼容：优先选择 CUDA 版，识别速度更快。
* 其他电脑或追求最高兼容性：选择 CPU 版，速度较慢但适用范围更广。
* CPU 与 CUDA 两个 ZIP 必须分别解压，不能互相覆盖或混合 _internal 目录。
* CUDA 版无法加载时，可以改用 CPU 版。

二、解压
--------

把整个 ZIP 解压到当前用户有写入权限的目录，例如“文档”或其他数据盘目录。
不要直接从 ZIP、Program Files、只读介质或只读网络共享中运行。

三、准备模型
------------

软件不会自动下载模型。请只从官方 Hugging Face 仓库准备以下两个文件：

仓库：SmilingWolf/wd-vit-tagger-v3
固定 revision：7f6b584d0bd3f55c4531f14ba3d4761b2bccdc0f

model.onnx
selected_tags.csv

放到解压目录中的：

models\wd-vit-tagger-v3\model.onnx
models\wd-vit-tagger-v3\selected_tags.csv

model.onnx 期望 SHA-256：
35f23693620b668f4d53fd3c62bf65e40af739bc52c7eb0fbc49258b58d065b6

模型许可证与 AnimeTagger Lite 软件许可证彼此独立；模型不会进入发行 ZIP。

四、开始识别
------------

1. 双击 AnimeTaggerLite.exe。
2. 打开“设置”，确认模型目录和设备。
3. 点击“验证模型”，再点击“加载模型”。
4. 拖入或添加图片。
5. 点击“开始识别”。
6. 在右侧检查标签并复制正向或正负提示词。

默认反向模式为 none，因此只会生成正向提示词。需要反向提示词时，把反向模式
改为 basic 或 cleanup_detected，并导出“正负 TXT”。LoRA Caption 模式按设计
不生成反向提示词。

五、数据与升级
--------------

图片不会上传，软件不会后台联网、检查更新、发送遥测或修改原图。配置、窗口
状态、日志、批任务和临时剪贴板图片只写入解压目录的 data\ 下。

升级时先关闭程序并备份旧版 data\，将新版解压到新目录，再按需复制配置。
不要用 CPU ZIP 覆盖 CUDA 目录，或反向覆盖。删除 models\ 只会移除本地模型，
不会影响用户图片、Caption 或导出文件。
