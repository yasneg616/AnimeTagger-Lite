AnimeTagger Lite 1.2.1 · 现代界面与调色盘

1.2.1：手动注入正向标签
在正向提示词下方输入模型没有的角色或其他标签（英文/中文逗号分隔），点击“注入正向”或按回车。
默认停用模型识别的发型、发色、瞳色、眉毛、睫毛、胡须等外观标签，保留表情、视线、服装和背景。
手动标签受保护；取消“清理已识别的发型 / 发色 / 面部特征”勾选可只追加标签。
注入标签不受模型词表、Profile 标签数量上限或排除词限制；切换 Profile / 重新生成后仍保留。
“撤销注入”恢复上一次注入前的结果；后续编辑或重新识别后撤销失效，以免覆盖新修改。
原始识别标签保留，JSON 与文本导出使用当前结果。重新识别同一图片会重置本次注入。


双击 AnimeTaggerLite.exe 启动。右上角“调色盘”提供暮紫、海蓝、青松、暖砂、晴昼主题，
也可自定义强调色、背景色、面板色。颜色实时预览，保存后自动记住，取消会恢复原配色。
顶部选择模型后可加载；“模型管理”中仍可验证和释放模型。
反向提示词、筛选和高级设置可展开，批处理与随机 Prompt 保留。

本次 single-EXE 版把 Python、Qt、推理运行库合并为一个程序，无需另装 Python。
models、resources、LICENSES 和 portable.flag 请保留在 EXE 旁边，整个目录一起移动。
模型已附带，无需重新下载。Canary 使用 CPU；WD v3 / PixAI 支持 CUDA。
单 EXE 每次启动会解压运行库到临时目录，启动可能需要等待十几秒至数十秒。
命令行使用 AnimeTaggerLite.exe --cli（替代单独的 AnimeTaggerLiteCLI.exe）。
单文件发行版以 BUILD-MANIFEST.json 中 program_layout=onefile 为准。

一、解压
--------

把整个 ZIP 解压到当前用户有写入权限的目录，例如“文档”或其他数据盘目录。
不要直接从 ZIP、Program Files、只读介质或只读网络共享中运行。

二、模型
------------

软件不会自动下载模型。查看 BUILD-MANIFEST.json 中的 model_included：
true 表示本包已经带上三个模型，可以直接使用；false 时需自行准备配套文件。

默认：WD EVA02 2026 Canary
目录：models/wd-eva02-tagger-2026-canary/
文件：model.safetensors、config.json、selected_tags.csv
来源：https://huggingface.co/ashen-sensored/wd-eva02-tagger-2026-canary

可选：PixAI Tagger v0.9（ONNX 转换版）
目录：models/pixai-tagger-v0.9/
文件：model.onnx、selected_tags.csv
来源：https://huggingface.co/deepghs/pixai-tagger-v0.9-onnx

旧模型：WD v3
目录：models/wd-vit-tagger-v3/
文件：model.onnx、selected_tags.csv
来源：https://huggingface.co/SmilingWolf/wd-vit-tagger-v3

模型许可证与软件许可证彼此独立；本包的模型哈希记录于 BUILD-MANIFEST.json。
当前多后端包的 Canary 使用 PyTorch CPU；WD/PixAI 可使用 ONNX CUDA。

三、开始识别
------------

1. 双击 AnimeTaggerLite.exe。
2. 打开“设置”，选择模型后端并确认模型目录和设备。
3. 点击顶部“加载模型”（验证与释放位于“模型管理”）。
4. 拖入或添加图片。
5. 点击“开始识别”。
6. 在右侧检查标签并复制正向或正负提示词。

默认反向模式为 none，因此只会生成正向提示词。需要反向提示词时，在“生成设置 → 高级设置”中把反向模式
改为 basic 或 cleanup_detected，并导出“正负 TXT”。LoRA Caption 模式按设计
不生成反向提示词。

四、数据与升级
--------------

图片不会上传，软件不会后台联网、检查更新、发送遥测或修改原图。配置、窗口
状态、日志、批任务和临时剪贴板图片只写入解压目录的 data\ 下。

升级时先关闭程序并备份旧版 data\，将新版解压到新目录，再按需复制配置。
不要用 CPU ZIP 覆盖 CUDA 目录，或反向覆盖。删除 models\ 只会移除本地模型，
不会影响用户图片、Caption 或导出文件。
