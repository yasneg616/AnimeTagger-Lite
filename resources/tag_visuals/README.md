# 标签图示与中文释义

单图标签表及随机 Prompt 标签列表使用本目录的离线数据。列表图标为 24×24，
悬停放大图为 160×160；英文标签保留。角色名称不制作图示。
在“单图 → 筛选与显示”中切换“图示辅助”，选择会自动保存并应用于两个列表。
图示开关不影响模型、Prompt、复制或 TXT/JSON 导出。

当前三个模型共有 12,030 个不同的一般标签，全部登记了处理结果：

| 状态 | 数量 | 含义 |
| --- | ---: | --- |
| `direct` | 1,164 | 已有具体形状、位置或动作图示 |
| `composed` | 1,993 | 已知形状与颜色、材质、动作或位置组合 |
| `schematic` | 121 | 用人数、箭头、局部或画面框等辅助示意 |
| `category_only` | 77 | 图标仅表示类别，含义见文字说明 |
| `pending` | 8,675 | 含义或图示尚未可靠核对，保留英文并注明原因 |

前三项合计 3,278 个。按三个 CSV 中最大的 `count` 排序，前 1,000 个一般标签
有 951 个提供前三类图示（95.1%）；类别提示不计入含义覆盖率。
作品名称另计为作品类别提示，不能由名称猜测作品形象。

- `coverage.tsv`：全量逐项清单，包括名称、类别、频次、独立图示分组、中文释义、状态、来源、方式及待补原因。
- `coverage.json`：各类统计、高频缺口、输入词表与释义文件的 SHA-256。
- `catalog.json`：按“类别 + 规范化名称”索引的界面映射。
- `terms.tsv`、`long_tail.tsv`：人工整理的中文释义与图示定义；中文为项目自编说明。
- `rules.json`、`primitives.json`：离线组合规则和原创 SVG 基础形状。
- `samples.json`、`review_samples.json`：48 个代表样例与 42 个长尾复核样例。

新手动标签可匹配已支持的颜色、材质、衣物、部位和动作组合，例如 `blue_shirt`、
`holding_umbrella`。未识别的修饰词不会仅凭其中出现 `hair` 或 `eye` 自动配图。
资源缺失、格式错误或 SVG 无法渲染时保留英文文字，并写入程序日志。

词义分类参考 [Danbooru 标签分组](https://safebooru.donmai.us/wiki_pages/tag_groups)。
本项目自行绘制全部 SVG，没有复制上游图片。图示为简化辅助；标签的条件、上下文和边界仍以释义为准。
