# 本机图示审阅网站

双击项目根目录的 `打开图示审阅网站.cmd`。网站只监听 `127.0.0.1`，默认地址为 `http://127.0.0.1:8766`；端口被占用时启动器会选择下一个空闲端口。重复打开会复用已经启动的网站。

正式便携包也提供同名启动文件，它调用包内 `AnimeTaggerLite.exe --review-icons`，无需安装 Python。首次启动单 EXE 需要解压运行库，启动器会等待本机服务就绪。便携包的反馈保存在该包自己的 `data/tag-visual-review/`；个人审阅记录不写入发行包，原项目记录继续保留。

所有现有图示都按标签列出。目前共有 4,031 项：具体图示 1,200、组合图示 1,993、场景示意 148、类别图示 690。同一基础素材用于多个标签时分别展示，便于判断颜色、动作、修饰词组合是否准确。角色名称和尚未绘制的标签没有图示，因此不列入画廊。

每项显示 160×160 的示意图、24×24 的列表图标、英文名称和中文说明。勾选「需要重做」会立即保存，取消勾选会从重做清单移除。点击图示可放大，并可为已经勾选的图示填写原因；原因需要点击「保存原因」。不勾选表示未标记重做，不代表系统已经确认你审阅过该项。

页面提供中英文搜索、分类、图示方式、标签类型、高频排序、深色预览、分页和「只看已勾选」。每页 72 项。筛选与页码保存在本机浏览器中，勾选及原因保存在后台，换浏览器或刷新也不会丢失。多个页面修改同一项时，版本检查会阻止旧页面覆盖新选择。

## 反馈与后续重做

后台数据位于 `data/tag-visual-review/`，与推理、Prompt 和导出功能相互独立：

- `reviews.sqlite3`：勾选与原因的持久化数据库。
- `rework.json`：每次保存后原子更新的重做清单，可直接由 Codex 在本项目中读取。
- `server.json`：当前网站的本机地址、进程号和实例信息。
- `server.stderr.log`、`server.stdout.log`：本机运行日志，不记录原因或请求参数。
- `server.runtime.log`：无控制台的便携 EXE 运行日志。

审阅完成后，在这个对话中说「读取网站后台的勾选结果并重做」即可。无需复制标签或上传文件。网页保存反馈本身不会自动唤醒 Codex；后续开始工作时可直接读取后台清单。此工具不创建定时任务，也不向任何外部平台发送消息。

页面上的「导出重做清单」可下载 JSON。关闭网站后，数据库和清单仍保留。还可以在项目目录运行以下命令读取最新反馈，无需运行网站：

```powershell
.\.venv311-cuda\Scripts\python.exe -m app.tag_visual_review --export
```

图示重新绘制后，稳定的标签身份继续保留反馈；页面会提示「图示已更新，旧标记仍保留」，由你自行决定是否取消勾选。图示版本由实际 SVG 内容及释义计算，修改一个图示不会使其他标签显示更新提示。

第一轮重制覆盖 77 项，定义在 `resources/tag_visuals/refinements.json`，只对列明的类别及标签生效。重新打开或刷新网站，勾选「只看已勾选」即可复审；这 77 项仍保留原来的勾选和原因。

## 隐私与启动

不进行公网部署，不使用 CDN、外部字体、统计、连接器或模型服务，不读取用户图片、Prompt 或配置。HTTP 仅提供明确列出的页面、图示及反馈接口，不开放项目目录。后台检查本机 Host、请求来源和会话令牌；跨站请求不能修改勾选。反馈目录不纳入 Git、程序资源或发布包。

可在 PowerShell 手动启动：

```powershell
.\.venv311-cuda\Scripts\python.exe -m app.tag_visual_review --port 8766
```

该方式可用 `Ctrl+C` 停止；双击启动器会在后台运行，关闭网页不会停止后台。无需安装额外依赖。端口选项只改变本机端口，不能绑定局域网或公网地址。
