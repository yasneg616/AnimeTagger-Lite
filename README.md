# AnimeTagger Lite 预览版应用源码还原

本快照还原原预览构建的全部 68 个应用模块，并保留原包的 resources、模型配置和词表。
每个应用模块均与原 EXE 中的可执行字节码核对一致，核对包括函数名、参数、常量、闭包、栈和异常表；只忽略源码位置和行号。

这是一份经过核对的应用源码还原，不声称完整复原当时的开发目录、测试目录或打包过程。模型权重、私人配置、图片和日志不在本快照中。

原便携程序： https://github.com/yasneg616/AnimeTagger-Lite/releases/tag/v1.3.0-preview.20261003

源码运行前按 requirements 文件准备依赖，并自行提供配套模型权重。离线便携使用仍可下载原版本 ZIP。
